版本更新说明 (v2.3.1)

v2.3 移动公众全量融合 · 移动爱家 SCG 底座打通与开机能力恢复 · 自动开机守护默认开启 (最新)
2026-09-28
  • 移动公众（中国移动云电脑 · 公众版）全量融合，三平台同台管理：新增独立登录通道（账号密码）与分层保活 —— L1 账号态探针 + L2 桌面登记，配套官方协议侧车；提供云电脑开机 / 关机 / 重启能力；新增静默会话信号（updateSessionStatus + pushConnectEventData，默认执行、界面与日志均不显示）与 accessToken 25 分钟主动续期（平台 TTL 约 30 分钟，消除周期性 401）。开关机状态改用合成判定（探测证据 > 平台操作能力表 > 平台状态字段），平台字段滞后或失真时界面不再跟着错。
    依赖说明：移动公众协议侧车需 Python 3（Docker 镜像已内置 python3 + requests + pycryptodome；本机直跑需自备）。天翼云与移动爱家仍为零 Python 依赖。
  • 移动爱家「深信服 SCG」底座打通（含开机能力恢复）：定位到 SCG「零应答」根因是缺少官方 CEM 控制面（firm-auth 的 scAuthCode 只是 OAuth 扩展授权令牌，必须经 CEM 换取会话材料）。现已实现 CEM 官方链路（OAuth 扩展授权 → getConnectInfo 触发开机 → getVmReadyStatus 就绪轮询），并打通 SCG 保活数据面（同 socket TLS 升级 + trunk/SPICE），真机验证：鉴权通过、会话建立并收到首帧 SPICE 数据。「名下云主机」恢复『开机』与『守护』控件。
    开机全程走账号自有凭据的官方通道：ZTE 走 CAG HTTPS（RSA 公钥动态获取 + 保留 TLS 证书校验），SCG 走 CEM 官方接口；不伪造客户端身份、不关闭证书校验。保活有效性仍按诚实口径标注（未被证明有效），以真机长期观察为准。
  • 「自动开机守护」默认开启（移动公众 + 移动爱家 SCG）：账号级 + 单机双开关、同机 10 分钟冷却、只对「确定关机」下发（绝不盲开）、时长耗尽熔断。移动公众一刀切默认开；移动爱家按底座分叉 —— 含 SCG 的账号默认开（CEM 通道，无额外代价），纯 ZTE 账号保持默认关（ZTE 开机走 CAG 会真实消耗限时套餐时长，需显式开启）。开关默认口径由单一判定入口驱动，界面与后端同源不漂移。
    如实说明：平台约 48 小时强制关机无法被 HTTP 层保活阻止，守护的职责是关机后自动恢复。
  • 30 天免登录：登录新增「30 天内免登录」勾选（默认勾选）。勾选后无论容器重启还是关闭页面都保持登录，只有点「退出」才吊销；服务端仅持久化勾选会话（原子写、权限 0600），未勾选绝不落盘，登出即吊销、重启不复活。
  • L3 层整层删除 + 日志降噪：未实现的 L3 占位层按要求从界面到底层整层删除；progress slow= 与 SCG 材料探测等重复日志合并折叠；token 主动续期不再输出「重登成功」误导性日志；关机提示按机去重，不再刷屏。
  • 稳定性与自愈：新增 Python 解释器真伪探测（拒绝 Windows 商店假 Python 的 9009 报错）与 10 分钟熔断退避；修复协议侧车并发启动竞态（重复拉起双进程）；面板进程新增退出取证（exit/SIGINT/SIGTERM 与未捕获异常持久化落日志），配合守护循环实现异常自动重启。
  • 质量网扩容：回归测试网扩至 202+ 项断言、变异验证扩至 120+ 项（覆盖守护默认口径、CEM 在途语义、会话持久化、静默信号等全部新特性）。CI 前置语法检查与回归闸门继续强制，任一失败即不构建、不推送镜像。
v2.2.5 挂机中断鉴别观察窗延长至 5 分钟
2026-09-23
  • 挂机中断鉴别的观察窗由 90 秒延长至 5 分钟：改为 5 次采样 × 60 秒 = 总计 5 分钟，以覆盖官方“按分钟粒度落账”的跳变边界；判定阈值仍为 30 秒增量：计时增长 → 判定有真人在用，立即让位避让；计时冻结 → 判定无人在用，允许重连续挂。
  • 便于定位根因的采样日志：新增逐分钟采样日志，可直观看出官方计时在 5 分钟内是否变化及变化节点。
  • 已知局限（如实说明）：本调整只在官方计时属于延迟落账时有效。
